# Fact System vs. Delivery System

## Summary

A distinction between protocols. Delivery systems (like WAMP or HTTP) define *how* data moves. Fact systems (like Op) define *what* data or operation exists, making the existence itself the primary concern. (Source: 14-the-fact-7e232060)
