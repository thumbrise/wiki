# Map and Territory Problem

## Summary

The challenge in conventional engineering where the description (the map, e.g., an OpenAPI spec) drifts from the actual running system (the territory, e.g., the server code). Op aims to eliminate this gap by making the map the territory. (Source: 14-the-fact-7e232060)
